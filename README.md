# Ветка: сайт цветочного магазина

**Открыть сайт: [personanongraat.github.io/flowers_shop](https://personanongraat.github.io/flowers_shop/)**

В Windows можно открыть файл `SITE.url` двойным щелчком.

Адаптивный шаблон на HTML, CSS и JavaScript. Без фреймворков, npm и обязательной сборки. Включает каталог, конструктор букета, корзину, оформление и форму обратной связи. Шапка закреплена при прокрутке.

## Открыть в VS Code

Откройте `vetka.code-workspace` двойным щелчком или выберите в VS Code «Файл > Открыть папку» и укажите папку проекта.

## Запустить

Простой просмотр: открыть `dist/index.html` в браузере.

Локальный сервер: запустите `start.cmd`, затем откройте http://127.0.0.1:4173. Нужен Python. Закрытие окна сервера останавливает сайт. Альтернативная команда из папки проекта:

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Также можно использовать расширение Live Server в VS Code. Корень указан в workspace: `/dist`.

## Адаптация под магазин

| Что изменить | Где |
|---|---|
| Название, город, контакты, часы, заголовки и доставка | `dist/config.js` |
| Имя автора и Telegram | `author`, `authorUrl` в `dist/config.js` |
| Букеты, цены, составы, категории | `dist/products.js` |
| Цветы для конструктора, упаковка и открытки | `dist/products.js` |
| Фотографии | `dist/assets/images/` |
| Отзывы, магазин-источник и ссылка 2ГИС | `dist/reviews.js` |
| Цвета, шрифт, скругления и адаптивность | `dist/styles.css` |
| Структура страницы и общие подписи | `dist/index.html` |

У каждого товара должен быть уникальный `id`. Значение `image` соответствует имени JPG без расширения. Фотографии локальные. Ссылки на оригиналы и условия: [PHOTO-SOURCES.md](PHOTO-SOURCES.md).

У доставки `price` и `freeFrom` задают расчёт, `text` описывает условия. Меняйте их согласованно. Название вкладки и описание страницы обновляются из конфигурации.

## Отзывы 2ГИС

Используется вручную подготовленная подборка настоящих коротких отзывов о конкретном салоне. Название источника видно на сайте. Меняйте магазин, ссылку и тексты вместе. Одна замена ссылки не скачивает новые отзывы. Автосинхронизация не подключена.

## Заказы и персональные данные

Приём заказов и оплата пока не подключены. Интерфейс сообщает об отсутствии отправки. `demo: true` оставляет оформление локальным. Имя, телефон, адрес и комментарии не сохраняются и никуда не отправляются. В localStorage остаются только состав и количество товаров корзины.

Для продаж реализуйте `submit` и `feedback` в `dist/order-adapter.js` через собственный сервер. Подробности: [документация](docs/PROJECT.md). `demo: false` само по себе отправку не включает.

## Публикация

На статический хостинг загрузите содержимое `dist`, сохранив структуру. Главный файл: `index.html`.

Репозиторий: https://github.com/personanongraat/flowers_shop

Для GitHub Pages подготовлен `.github/workflows/pages.yml`: после отправки изменений в `main` он публикует содержимое `dist`. В настройках репозитория `Settings > Pages > Source` выберите `GitHub Actions`. После успешного выполнения публикации сайт доступен по адресу https://personanongraat.github.io/flowers_shop/ . При необходимости запустите `Actions > Publish flower shop > Run workflow`.

## Проверка

Проверены каталог, сортировка, конструктор, разные составы в корзине, сохранение после обновления, доставка и самовывоз, телефон, форма обратной связи, закрытие окон и возврат фокуса. Проверены размеры 360 и 1440 px. После правок первого экрана проверены отсутствие длинных тире в видимом тексте и отсутствие ошибок JavaScript.

В проекте нет ключей сервисов, платёжной интеграции или базы заказов. Общая лицензия на распространение кода не задана; права на фотографии описаны отдельно.
